# 阶段观照表和季节表

## 一、阶段观照表（观一样东西，填一张）

填完不改，过三个月、半年再拿出来对照。

| 项目 | 怎么填 |
| --- | --- |
| 日期、东西 | 哪一天，观的是什么，观的是哪一个圈（比如周线，半年到一年） |
| 它的锚 | 价格最后靠什么兑现，谁说了算，谁当家 |
| 它的圈 | 靠什么转，一圈大概多长，现在在大圈的哪里 |
| 上一段 | 已经走完、观得清的那一段，凭什么这么说 |
| 观条件 | 事实在往哪边变：不再变坏、开始变好、不再变好、开始变坏 |
| 观时机 | 钱在进还是在出，人气在聚还是在散，趋势往哪边走 |
| 观人性 | 说了算的那拨人做了什么，是贪还是怕，到头没有；我自己心里在想什么 |
| 消息 | 最近的消息对不对，想让人干什么，价格的反应是什么 |
| 几股力在正面 | 是哪几股；当家的那股力往哪边走 |
| 现在在哪一段 | 上涨六段还是下跌六段，第几段 |
| 出现什么说明观错了 | 写一个看得见的价格或者事情 |
| 最坏的结果 | 认错的位置在哪，最多亏多少钱，能不能接受 |
| 怎么做 | 狠、拿、忍、断，还是趴着；做多大 |
| 事后对照 | 过三个月、半年以后，实际走成了哪一段，观对了没有 |

### 填好的例子：2014年7月底的上证指数（事后整理，当时的数据为准）

| 项目 | 内容 |
| --- | --- |
| 日期、东西 | 2014年7月底，上证指数，看周线这个圈 |
| 它的锚 | 政策和钱；说了算的是杠杆资金和监管；人和当家 |
| 它的圈 | 信贷和政策推着转，三四年一小圈；2009年以后跌了好几年，在大圈的冬天里 |
| 上一段 | 衰竭：前几个月成交越来越少，坏消息出来跌不动，没人谈论 |
| 观条件 | PMI从年初的50.2升到51.7，PPI的跌幅从-2.3%收窄到-0.9%，定向降准出来了：事实不再变坏，开始变好 |
| 观时机 | 7月24日三个月来第一次站上2100点，放量上涨，低点没有再破 |
| 观人性 | 融资余额6月约4034亿、7月约4400亿，借钱的人开始加码；市场上的话还是“又来骗人了” |
| 消息 | 政策利好出来，指数涨得动了，跟以往“利好出尽”不一样 |
| 几股力在正面 | 时机在翻、杠杆资金开始加，当家的那股力往上走 |
| 现在在哪一段 | 上涨六段，衰竭刚走完，进入绝望，往怀疑走 |
| 出现什么说明观错了 | 跌破年初的低点1991点 |
| 最坏的结果 | 认错放在1991点下方，离2105点约5%，小仓位能接受 |
| 怎么做 | 三分之一先站位置，回踩不破再加到三分之二 |
| 事后对照 | 之后走完怀疑、犹豫，12月进入大众共识，2015年3到5月泡沫，6月12日兑现见顶 |

## 二、季节表（同时观好几样东西，一张表对照）

| 东西 | 锚 | 谁当家 | 上一段（已走完） | 现在 | 下一段 | 条件在变好还是变坏 | 出现什么说明观错了 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| （例）某根茎类药材 | 实物 | 条件 | 衰竭 | 绝望 | 怀疑 | 减种、库存不再增加 | 报价跌破前低 |
| （例）某果实类药材 | 实物 | 条件 | 大众共识 | 泡沫 | 兑现 | 开始松动：扩种的消息变多 | 涨势放缓、说贵的人又多起来（那还没到泡沫） |
| （例）某A股指数 | 政策和钱 | 人和 | 麻木 | 恐慌 | 衰竭 | 杠杆还在减 | 放量站上前高 |

把大圈和小圈对起来看：大圈在春天、小圈刚从衰竭转到绝望，是两个圈对上了，可以出手；大圈在秋天，小圈哪怕走出一个漂亮的绝望，也只能当作下跌途中的反弹。
