## 1. 通用办法

每一股力找两三样看得见的数。每一样数都按下面的办法处理，再在同一股力里取平均：

1. **定好方向**：让“数变大”等于“对价格是好事”。库存、解禁、母猪存栏增长这类对价格是坏事的，取负号。
2. **和它自己的历史比**：用它过去的全部数据算出一般水平和波动，算出现在高出一般水平多少（标准分）。至少要有三年历史，个股业绩至少八期。比一般水平好，算正面（零上）；差，算反面（零下）。
3. **去毛刺**：取最近3个月的平均。
4. **看方向**：拿现在的3个月平均和3个月以前比，变大了是“往上走”，变小了是“往下走”。3个月没变化的，沿用上一次的方向。
5. **四种状态**：往上走、还在零下，是“反面走完了”；往上走、到了零上，是“正面出来了”；往下走、还在零上，是“正面走完了”；往下走、到了零下，是“反面出来了”。

时机这一股力，没有别的数据时，用价格自己算：

- 收盘价离10个月均线多远（周线用40周均线）；
- 最近6个月涨跌；
- 成交量：最近3个月平均比最近12个月平均。

`scripts/stage_tool.py` 就是按这个办法算的。

## 2. 只用当时看得到的东西

- 宏观月度数据（PMI、PPI、M1、信贷、工业增加值、用电量、房地产）：第N月的数，N+1月中旬才公布，月底判断时只用到上个月。
- 公司业绩、股东户数、大股东增减持：按**公告日**，不按报告期。
- 母猪存栏：本月的数下个月公布。它领先生猪出栏大约十个月，所以“十个月前的母猪存栏在减”，说的是“现在的供给在减”。
- 价格、成交、持仓、融资余额：用到当天收盘。

回头复盘时，尤其不要用事后才知道的数去倒推当时的判断。

## 3. 各类东西的三股力

### 生猪（锚：实物；条件当家；圈：大约四年）

| 力 | 看什么 | 正面是 |
| --- | --- | --- |
| 条件 | 能繁母猪存栏（十个月前的变化决定现在的供给）、生猪存栏和出栏、冻肉库存、养殖利润（猪粮比） | 供给在减、库存在降 |
| 时机 | 生猪价格的趋势、生猪期货、成交 | 价格低点抬高、钱在进 |
| 取舍（养殖户） | 补栏还是淘汰母猪（仔猪价格、二元母猪价格）、压栏和二次育肥、出栏体重 | 在补栏、压栏（贪）；在淘汰、恐慌出栏（怕） |

亏到养不下去、大家淘汰母猪，十个月后猪少了，价格回来，这就是生猪的冬里藏春。

### 中药材（锚：实物；条件当家；圈：看品种的生长期，三到五年常见）

| 力 | 看什么 | 正面是 |
| --- | --- | --- |
| 条件 | 种植面积、产新量、社会库存和药商库存、药厂采购和出口、天气和灾害 | 减种、减产、去库存 |
| 时机 | 主要药市（亳州、安国、玉林、荷花池等）的价格趋势、成交和问价 | 问价的人多、报价抬高 |
| 取舍（药农、药商、游资） | 扩种还是弃种，囤货还是抛货，借钱囤货的人多不多 | 在囤、在扩（贪）；在抛、在弃（怕） |

品种不同，圈的长短差得很远：一年生的圈短，多年生根茎类的圈长。先认清这个品种的生长期。

### 工业品期货（锚：实物；条件当家；圈：跟着经济和产能，三到五年）

| 力 | 看什么 | 正面是 |
| --- | --- | --- |
| 条件 | 宏观：PMI、PPI同比、M1同比、工业增加值同比、工业用电量同比；黑色（螺纹、热卷、铁矿、焦煤焦炭、玻璃、纯碱）再加商品房销售额和房地产投资同比。品种自身：交易所库存和社会库存（越低越好）、现货比期货贵（基差为正说明现货紧）、开工率 | 需求在变好、库存在降 |
| 时机 | 价格离均线多远、6个月涨跌、成交量 | 趋势向上、放量 |
| 取舍 | 持仓量（近3个月比近24个月）：下注的人在加码还是撤退；产业扩产、减产的动作 | 在加码 |

期货本质是对手盘：短期谁挤在一边谁被收割，所以持仓量很高、所有人都押一边的时候，要防人性到头。

### A股指数（锚：政策和钱；人和当家；圈：信贷和政策，三四年一小圈）

| 力 | 看什么 | 正面是 |
| --- | --- | --- |
| 取舍（当家） | 全市场融资余额6个月变化（加杠杆还是去杠杆）；新股加增发12个月合计占总市值（发行节奏，也是监管的松紧）；大股东净减持；救市资金进出 | 在加杠杆、发行在加快 |
| 条件 | PMI、PPI、M1、信贷社融、工业增加值、用电量；降准降息等政策 | 经济和政策在变好 |
| 时机 | 指数离均线多远、6个月涨跌、成交额、新开户 | 趋势向上、成交放大 |

A股是结构性的：上证里银行能源多，创业板里成长股多，同一时间可以一个在冬天、一个在春天，要按指数分别认圈。政策常在跌狠了以后出手，所以政策动作常出现在冬至附近，但它是跟着来的，不是先知先觉。

### 个股（锚：将来的钱；先看大圈）

1. **先看大圈**：它所在的大盘、行业在哪个季节。个股自己的东西判断不准上下半圈，跟着大圈走更靠谱。
2. **再看它比大圈强还是弱**：

| 力 | 看什么 |
| --- | --- |
| 条件 | 行业的条件（资源股看它卖的东西的价格和库存，养殖股看猪价和存栏，地产股看销售），其次才是公司业绩的方向（股价常提前反应业绩） |
| 时机 | 股价趋势、成交 |
| 取舍（说了算的人） | 大股东和高管增持还是减持、股权质押、限售解禁（解禁前大股东有了卖的可能）、回购、定增；融资余额；股东户数（散户在往里挤还是往外撤） |

先查：有没有人要减持、要解禁。利好常常是给减持铺路的。

### 加密货币（比特币、以太坊）

**第零步：**

- **锚**：没有现金流，也不被吃掉、用掉，价格靠资金和共识，是软锚，接近“政策和钱”这一类。比特币有一样硬事实：供给按约四年一次的减半往下降（2012、2016、2020、2024年，下一次约2028年）。
- **谁说了算**：长期持有的大户、现货ETF和上市公司的“比特币金库”、矿工（挖出来要卖）、杠杆资金（期货和永续合约）、各国监管，尤其是美国的态度。
- **圈**：大致四年一圈，跟着减半和全球流动性走。比特币过去几轮的顶在减半后约一年到一年半（2013年12月、2017年12月、2021年11月、2025年10月），顶后大约一年见底（2018年12月、2022年11月），跌幅一轮比一轮小。按芝商所比特币期货：2017年顶到底约跌84%，2021年那轮约跌78%，2025年10月6日最高约126,130美元，到2026年6月30日最低约58,805美元，跌了53%。
- **谁当家**：人和，即杠杆资金和大资金的动作，再加流动性。
- **以太坊**：先看比特币这个大圈，再看以太坊和比特币的比价（ETH/BTC）是变强还是变弱；以太坊自己的条件看链上活动、手续费、质押和ETF资金。

| 力 | 看什么 | 正面是 |
| --- | --- | --- |
| 取舍（当家） | 期货持仓量和资金费率（杠杆在加还是在减）、爆仓规模、长期持有者在囤还是在卖、交易所里的币在减少还是增加、ETF和上市公司在买还是卖 | 杠杆在加、大户在囤、ETF在买 |
| 条件 | 全球流动性（美联储利率方向、美元流动性）、稳定币总量增速、ETF净流入、减半后的供给变化、监管政策 | 流动性在变松、新钱在进 |
| 时机 | 价格离40周均线多远、6个月涨跌、成交 | 趋势向上 |

一次大规模爆仓（杠杆一下子被清掉），常常是人性的正面走完，即“恐慌”的样子。

### 房子、行业、一门生意、一个账号

- **房子**：条件看销售面积、库存去化时间、开发投资、人口；时机看房价趋势和成交量；取舍看开发商拿地、购房者加杠杆（按揭）。
- **一门生意**（做生意的人用）：条件看订单、库存、毛利；时机看客流、询价；取舍看同行在扩产还是在退出。春天备货，夏天放量，秋天收，冬天藏。
- **一个自媒体账号或一个题材**：条件看题材本身有没有新东西；时机看流量和平台推荐；取舍看创作者在扎堆还是在撤离。

## 4. 哪些判断更靠得住（经验）

作者用真实数据随机抽题、遮住后面的行情试过多次，大致是这样：

- **实物类用条件分上下半圈最靠得住**：工业品期货上，十次大约对六次；只看价格大约对五次，和瞎猜差不多。三股力也确实大致按“条件先、人性后”的顺序在转。
- **A股指数看杠杆资金和发行节奏**：十次大约对六次；只看经济条件只比瞎猜好一点。
- **个股**：用它自己的业绩、大股东动作、融资余额去分上下半圈，都和瞎猜差不多；跟着大盘的季节稍好一些。所以个股先看大圈。
- **只看价格、均线、人气**：分不清上半圈还是下半圈。
- **具体哪一段**：遮住未来的判断，和事后回头标的阶段比，正好同一段的大约一成，差一段以内大约三成。所以结论以上半圈、下半圈为主，具体哪一段说“大概”。
- **“到头”难认**：用“热度在零上、还在往上”认出来的兑现，往往是正热的时候，之后还在涨。认兑现、衰竭，要看到了极端、开始回头，并用价格信号核对（好消息不涨、坏消息不跌）。
- **按火候做买卖**：最大回撤大约少一半，赚得通常不比一直拿着多。它管的是少亏钱。
- **生猪、中药材**：锚最硬，按理说最准，但缺长历史的存栏、种植面积、库存数据，还没系统试过。

给结论时，把握照这个来定：实物看条件、A股指数看杠杆，可以说得肯定些；个股、只有价格的东西、具体哪一段，要说得保守些。

## 5. 数据从哪来

能连上就用，连不上就明说缺什么：

- **A股、港股、美股的价格**：各大行情软件，或者腾讯、新浪的行情接口。
- **国内期货（含持仓量）**：新浪期货日线；海外的芝商所比特币期货、伦敦金属等，新浪也有。
- **中国宏观、融资余额、增减持、解禁、业绩、股东户数**：东方财富数据中心。
- **生猪**：农业农村部的月度存栏数据，以及猪价网站。
- **中药材**：中药材天地网、药市报价，作者常用的易屯网。
- **加密货币**：CoinGecko、CoinMarketCap（claude.ai 上有现成的连接器）、交易所接口、ETF资金流数据；用户的 TradingView 可以导出图表数据（CSV）。
