# 冬至理论

一句话：**冬里藏春，夏里藏秋。** 最冷的时候，春天已经藏在里面；最热的时候，秋天已经藏在里面。为什么？**事先变，人后觉**：事情（条件）先变，价格给人的冷和热慢半拍。所以判断要**以条件为准，没有偏好**。

这个技能教你用作者的方法，把一个东西“观”清楚：它在上半圈还是下半圈，大概在十二段里的哪一段，接下来可能是哪一段，现在该狠、该拿、该忍、该断，还是该趴着。它**只定位置，不算时间**：说得出季节，说不出哪天见顶见底。

## 先记住这套框架

**三股力，每股有正反两面，就是“屋里的六个人”：**

| 力 | 老话 | 是什么 | 正面 | 反面 |
| --- | --- | --- | --- | --- |
| 条件 | 地 | 事实：供求、库存、产量、盈利、政策，看的是**往哪边变**，不是眼下好坏 | 事实在变好 | 事实在变坏 |
| 时机 | 天 | 人气、钱、趋势 | 人气在聚、钱在进、趋势向上 | 人气在散、钱在走、趋势向下 |
| 人性（取舍） | 人 | **说了算的那拨人**的贪和怕，看他们**做了什么**，不看嘴上说什么 | 贪：加码、扩产、加杠杆 | 怕：撤退、去产能、还钱 |

**顺序：条件先转，时机跟着，人性最后走到头。** 上涨时一股一股翻到正面，下跌时按同样顺序翻到反面。正面走完了，就走反面；反面走完了，就走正面。

**十二段，每一段是一股力在翻面：**

| 段 | 哪股力在翻面 | 口头禅 | 价格信号 | 该做什么 |
| --- | --- | --- | --- | --- |
| 1 绝望 | 条件的反面走完 | “回本就卖”“又来骗人了” | 坏消息不跌，低点不破 | 小钱先站位置 |
| 2 怀疑 | 条件的正面出来 | “反弹而已”“等回调再买” | 低点抬高，回调很浅 | 回踩不破就加 |
| 3 犹豫 | 时机的反面走完 | 一半人信一半人不信 | 涨时放量，跌时缩量 | 主仓上，拿住（最该狠） |
| 4 大众共识 | 时机的正面出来 | “买少了”“还能上车吗” | 越涨越陡，成交很大 | 拿稳，不追加 |
| 5 泡沫 | 人性的反面走完 | “这次不一样”，没人说卖 | 近乎直线，上下晃得厉害 | 不买新的，盯住条件 |
| 6 兑现 | 人性的正面到头 | “洗盘”“拿住就是格局” | 好消息不涨，新高又跌回 | 减仓，破位就走 |
| 7 幻想 | 条件的正面走完 | “正常回调”“上车机会” | 跌时放量，反弹过不了前高 | 忍住不抄底，反弹时减 |
| 8 侥幸 | 条件的反面出来 | “不卖不算亏”“我做长线” | 高点低点一起往下 | 断舍离 |
| 9 瓦解 | 时机的正面走完 | “这么便宜为啥还跌” | 好消息不涨，坏消息大跌 | 趴着，不补仓 |
| 10 麻木 | 时机的反面出来 | “不看了”“装死” | 反弹越来越弱，成交越来越少 | 空着，记下不跟跌的 |
| 11 恐慌 | 人性的正面走完 | “割了”“销户” | 加速下跌，成交放大 | 不抄底，借钱的先减 |
| 12 衰竭 | 人性的反面到头 | “这还有人看？” | 坏消息不跌，没人谈论 | 观条件，等信号 |

冬至在衰竭和绝望之间（人性怕到头，条件开始回头）；夏至在兑现和幻想之间（人性贪到头，条件开始转身）。每一段的详细描述、怎么认、该怎么做和交易场景，在 `references/十二阶段速查.md`。

## 一定要给出明确的判断

用户要的是判断，不是一堆“可能”。每次都要给出：

1. **上半圈还是下半圈**（必须二选一）；
2. **大概哪一段**（可以写“犹豫到大众共识之间”这样的两段之间）；
3. **把握：高、中、低**，并说一句为什么。比如“实物类，条件数据齐，高”“只有价格，没有条件和取舍数据，低”；
4. **现在该怎么做**，以及认错线。

数据不全时也要给结论，同时把把握降下来，并写明缺什么、补上什么能让判断更准。只有当家的那股力完全看不清时，才说“观不清，以条件为准；条件也观不清就不动”，这本身也是一个明确的做法。

## 判断的六步

按顺序走。每一步都写出“凭什么”，也就是看到了哪个事实、哪个数，不要只给结论。

### 第零步：认清这个东西（锚、谁说了算、圈）

先问三句，因为同一套三股力，在不同的东西上“谁当家”不一样，选错了，后面怎么观都是白观：

1. **它的价格最后靠什么兑现？（锚）** 实物（猪、药材、粮食、金属、能源，期货到期要交割）锚最硬；将来的现金流（个股）价格常跑在已公告的业绩前面；政策和钱（A股指数、很多“没有现金流”的东西）锚最软。
2. **谁说了算，他要什么？** 这决定“人性/取舍”看谁：种的人养的人（补栏还是淘汰、扩种还是弃种）、大股东和产业资本（增持还是减持、质押、解禁、定增、回购）、监管（新股发多发少、救市还是降温）、杠杆资金（融资余额、期货持仓）、期货里的套保方和投机方。
3. **圈靠什么转，一圈多久？** 母猪到出栏约十个月，生猪约四年一轮；果树三四年；药材三五年；产能建设三五年；信贷三四年一小圈；比特币大致跟着四年一次的减半和全球流动性；整个经济的大圈几十年。圈认错了，就会在一个大圈的夏天里死等冬天。

然后定一件事：**先认锚，再定谁当家。**

| 锚 | 例子 | 谁当家 | 观什么 |
| --- | --- | --- | --- |
| 实物 | 生猪、中药材、粮食、铜、钢材、化工品 | 条件（地利） | 供求：存栏、种植面积、产量、库存、开工；工业品再看经济往哪边走（PMI、PPI、用电量、地产） |
| 政策和钱 | A股指数、加密货币这类靠资金和共识定价的东西 | 人和：杠杆资金、发行节奏、说了算的大资金 | 融资余额在加还是减，新股增发多发还是少发；加密货币看杠杆（持仓、资金费率）、大户和ETF在买还是卖、稳定币和全球流动性 |
| 将来的钱 | 个股 | 先看大圈 | 大盘和行业在哪个季节；个股自己的东西只决定它比大圈强还是弱 |

**天时不当家**：只看价格和人气，分不清上半圈还是下半圈。价格是用来验证的，不是用来定方向的。

还要问一句：**它还会有新的东西吗？** 冬天之后一定有春天；没有春天的，不是冬天，是死了（被替代的技术、退市的公司、消失的需求）。条件永远不回头的，别等它的春天。

### 第一步：收集事实

- 优先找当家那股力的数据，其次是另外两股力。每一样尽量拿到足够长的历史，至少覆盖上一轮完整的涨跌，这样才能和它自己的过去比。
- **只用当时看得到的东西。** 宏观数据一般晚半个月到一个月公布；公司业绩、股东户数、增减持按公告日；不要拿事后修订、事后才知道的数去倒推当时的判断。
- 事实和话分开：产量、库存、订单、公告、真金白银的成交是事实；“前景广阔”“风险加大”“这次不一样”是话。
- 每一类东西看哪些数、去哪找、怎么换算成“正反面”和“方向”，见 `references/三股力怎么观.md`。
- 手上有价格表格（可以再加条件、取舍的列）时，先用小工具算一个参考结果，再按下面几步判断。列名用“条件_”“条件反_”“取舍_”“取舍反_”开头（“反”表示越大越坏），宏观、业绩这类有公布滞后的，用 `--lag-cond 1` 往后挪一期：

```bash
python3 scripts/stage_tool.py 数据.csv --anchor 实物 --lag-cond 1
```

`--anchor` 填 实物、政策和钱、将来的钱；`--freq W` 改成按周算。小工具只给参考，不替代下面的判断。

### 第二步：观三股力的正反面

每一股力看两样：**现在在正面还是反面**（和它自己的历史比，好过一般水平算正面），**最近在往哪边走**（这几个月在变好还是变坏）。合起来有四种状态：

| 方向 | 还在反面（零下） | 已在正面（零上） |
| --- | --- | --- |
| 往上走 | 反面走完了 | 正面出来了 |
| 往下走 | 反面出来了 | 正面走完了 |

人性/取舍要看说了算的人**做了什么**：外面看热闹的人怎么说、你自己怎么想，都不算。

### 第三步：当家的那股力，定上半圈还是下半圈

当家的那股力往上走，就是上半圈（绝望到兑现）；往下走，就是下半圈（幻想到衰竭）。实物看条件；A股指数看杠杆资金和发行节奏；个股先看大盘和行业的季节。

**能分清上半圈还是下半圈，已经很够用了。** 经验上，这一步做对的把握远大于“具体哪一段”。

### 第四步：其他两股力，定在半圈里的哪一段

按“条件先、时机跟、人性最后”的顺序对号：

| 条件 | 时机 | 人性 | 阶段 |
| --- | --- | --- | --- |
| 往上 | 往下 | 往下 | 条件还在零下：绝望；到了零上：怀疑 |
| 往上 | 往上 | 往下 | 时机还在零下：犹豫；到了零上：大众共识 |
| 往上 | 往上 | 往上 | 人性还在零下：泡沫；到了零上：兑现（看是否到了极端、开始回头） |
| 往下 | 往上 | 往上 | 条件还在零上：幻想；到了零下：侥幸 |
| 往下 | 往下 | 往上 | 时机还在零上：瓦解；到了零下：麻木 |
| 往下 | 往下 | 往下 | 人性还在零上：恐慌；到了零下：衰竭 |
| 往上 | 往下 | 往上 | 观不清 |
| 往下 | 往上 | 往下 | 观不清 |

再用两样东西核对：

- **回头观，不是回头看。** 看前面哪一段已经走完了、观得清（比如前一阵人人喊割、借钱的被强平，说明人性的正面走完了）。阶段一段一段走，很少往回跳，也很少一下跳好几段；上回是瓦解，这回一涨就说绝望，中间几段都没看到，多半看错了。
- **对照价格信号和口头禅**（上面的十二段表）。价格是验证，不是定方向。

**“到头”最难认。** 兑现、衰竭要看“到了极端、开始回头”，光看“在零上、往上走”只能说明正热，不能说明到顶了。宁可说“上半圈后段，热，注意兑现的信号”，也别硬说“已经见顶”。

**观不清的时候**：以条件为准；条件也观不清，就不动。

### 第五步：写下观错的信号

每次判断写一句：**出现什么，就说明我观错了。** 比如观的是绝望，就写“要是跌破前面的最低点，说明条件还没转完”；观的是兑现，就写“要是放量创出新高并站稳，说明人性还没到头”。写在前面，错了才认得快。

### 第六步：算好最坏，再说怎么做

- **最坏的结果你能接受，就可以去做。** 先定认错的位置：绝望段放在前面的最低点，怀疑段放在最近一个抬高的低点，犹豫段放在上一次回调的低点。买入价到认错位置差多少，乘上数量，就是最多亏多少；接受不了就少买，别为了多买把认错位置往远处挪。
- **没有预期，就是最好的预期。** 不定“这把要赚几成”，条件撑着就拿，条件不撑就走。要守住的底线是：**别让预期压过认错线**，没到目标照样认错。
- **条件和时机怎么配**：条件撑着、时机也顺，狠；条件撑着、时机还逆，忍（小钱先站位置）；条件不撑、时机还顺，不追（热是虚的，有的减）；两样都不对，趴（像乌龟一样趴着，有货的断舍离）。两样冲突，以条件为准。
- **火候（占计划仓位的比例）**：绝望三分之一；怀疑三分之二；犹豫全部；大众共识全部，不再加；泡沫不加新的；兑现减一半以上；幻想、侥幸拿着剩下的，跌破认错线清零；瓦解到衰竭为零。
- **大圈定方向，小圈找时机**：周线（或月线）的大圈决定做不做、最多做多大，日线的小圈决定哪天进出。大圈在秋天，小圈的“绝望”只能当反弹。

市场只有一个方向：不是做多，也不是做空，而是**做对**。对的时候狠，错的时候忍、断舍离。势对了像老虎一样扑上去，势不对像乌龟一样趴着。

## 消息怎么看

先辨**对不对**（是不是事实，能不能对上产量、库存、订单、公告、成交）：对的，归到条件里去观，动机是次要的；对不上、只是话的，才去问动机（谁放的、什么时候放的、想让你干什么）。最后都看价格的反应：好消息不涨是兑现的样子，坏消息不跌是绝望的样子。**消息是话，反应是钱。**

## 交付格式

单个东西，用这个结构写，大白话，短句，少用术语（用了就顺手解释）：

```
# {东西}：现在在{上半圈/下半圈}，大概是「{阶段}」
一句话：{季节 + 为什么 + 现在该怎么做}

## 第零步：认清它
- 锚：{靠什么兑现}
- 谁说了算：{哪拨人，他们要什么}
- 圈：{靠什么转，一圈多久，现在在大圈的哪里}
- 谁当家：{条件 / 人和 / 先看大圈}

## 三股力
| 力 | 正面还是反面 | 往哪边走 | 凭什么（事实、数据、日期） |
| 条件 | | | |
| 时机 | | | |
| 人性（取舍） | | | |

## 在哪一段
- 上半圈还是下半圈：{由当家的那股力定，理由}
- 大概哪一段：{阶段}；前一段 {阶段} 走完了吗，凭什么
- 下一段可能是：{阶段}，出现 {什么} 就说明到了

## 怎么做
- 火候：{仓位上限}
- 认错线：出现 {什么} 就说明观错了
- 最坏：{认错位置、最多亏多少}，能接受才做

## 拿不准的地方
{缺了哪些数据、哪一步观不清、为什么}

只定位置，不算时间。以上是按冬至理论做的阶段判断，不构成投资建议。
```

同时观好几个东西（对照分析、季节表），用一张表：东西｜锚｜谁当家｜上一段（已走完）｜现在｜下一段｜条件在变好还是变坏｜出现什么说明观错了。大圈和小圈错开的地方（比如经济在秋天、某个行业在春天）单独点出来，那往往最有价值。

用户要的是记录、复盘，就用 `references/观照表模板.md` 里的观照表，填完不改，过三个月、半年再对照。

## 要守住的几条

- **只定位置，不算时间。** 不报目标价，不说“几月见顶”。
- **数据没有就说没有。** 缺条件或取舍数据时，明说“这一股力没看到数据，只能用价格代替，把握小”，别用价格硬编一个条件出来。凭记忆说的近期事实，标明“需要核实”。
- **实物看条件，A股指数看杠杆和发行节奏，个股先看大圈。** 只有价格时，只能说时机这一股力的状态，分不清上下半圈。
- **钱推起来的行情，条件会暂时失灵**（比如2015年A股，利润在降，价格翻倍）。这时要说清楚“条件不撑，热是虚的”，也要承认时机一时压过了条件。
- **用的人越多，季节越会提前**：大家都在绝望段买，绝望段就短。越是这样，越要以条件为准，因为条件不会因为大家信这套理论就变。
- **说的是作者的理论**：用作者的说法（冬里藏春、三股力、屋里的六个人、观、做对），不要换成别的理论名词，也不要说这套理论来自别处。
- **不替人下单、不动钱**；不承诺赚钱。这套方法主要让人少亏钱：分清季节、管住火候、守住认错线。

- `references/三股力怎么观.md`：各类东西（生猪、中药材、工业品、A股指数、个股、加密货币、行业、生意）的三股力看哪些数、去哪找、怎么换算；哪些判断更靠得住。收集数据、给结论定把握时读。
- `references/观照表模板.md`：阶段观照表和季节表模板，附一个填好的例子。
- `references/冬至理论原文.md`：论文全文。需要引用原话、讲道理、讲案例（附录二是2014到2016年A股的一轮真实行情）时读。
- `scripts/stage_tool.py`：从价格表（可加条件、取舍数据）算出三股力的状态和阶段，给第二到第四步一个参考。
